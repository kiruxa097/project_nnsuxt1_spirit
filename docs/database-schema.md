# Схема базы данных (PostgreSQL)

## Таблицы оркестратора
| Таблица | Назначение |
| :--- | :--- |
| `users` | Пользователи системы (`ANALYST`, `RISK_MANAGER`, `ADMIN`, `SCHEDULER`) |
| `processes` | Реестр бизнес-процессов (`BP-01`–`BP-04`, `PAYMENTS_SYNC`), ресурсы, зависимости, политики дублей |
| `resources` | Ресурсы системы и тип партиционирования (`DATE`, `PERIOD`, `CLIENT_LIST` и др.) |
| `tasks` | Запуски процессов, ключ идемпотентности, статус, приоритет (1–5), версия результата |
| `task_resources` | Связь конкретного запуска с запрашиваемыми ресурсами и режимом (`READ`/`WRITE`) |
| `locks` | Активные блокировки ресурсов с арендой (`lease_expires_at`) и `last_heartbeat_at` |
| `task_dependencies` | Предметные зависимости запуска от других процессов |
| `execution_logs` | Неизменяемый журнал решений оркестратора |

## Таблицы банковской предметной области
| Таблица | Назначение |
| :--- | :--- |
| `clients` | Клиенты банка (регион, тип, доход, версия данных) |
| `credit_applications` | Заявки на кредит |
| `loans` | Выданные кредиты и JSONB-графики платежей (`payment_schedule`) |
| `payments` | Плановые и фактические платежи по кредитам |
| `risk_results` | Результаты `BP-01` (`APPLICATION_CHECK`), `BP-03` (`OVERDUE_MONITORING`), `BP-04` (`PORTFOLIO_REPORT`) |

## Статусы запуска (`tasks.status`)
`CREATED` → `QUEUED` → `RUNNING` / `COMPLETED` / `FAILED` / `CANCELLED` /.

## Приоритеты (`tasks.priority`)
1 — Критически важный · 2 — Важный · 3 — Средний · 4 — Обычный · 5 — Низкий.
